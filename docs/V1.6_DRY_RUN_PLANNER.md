# ARTEL Power Platform MCP V1.6 — Dry-Run Planner

V1.6 agrega una capa de policy/planning sobre los inspectores PBIR/TMDL ya certificados. No introduce escrituras.

## Nuevas capacidades

- `artel_extension_info`
- `artel_tmdl_assess_local_security`
- `artel_plan_local_bi`

## Seguridad del modelo

`expect_rls` expresa una expectativa del consumidor. La ausencia de RLS solo se eleva a `HIGH` cuando el caller declara que requiere aislamiento.

La inspección sigue siendo estática:

```text
semantic_runtime_validated=false
runtime_certification_required=true
```

Un rol TMDL o `tablePermission` no certifica identidad efectiva ni aislamiento real. Esa certificación pertenece a un gate runtime posterior.

## Planning contract

Todos los planes V1.6 declaran:

```text
mode=DRY_RUN
apply=false
checkpoint_required_before_apply=true
runtime_validation_required=true
```

El planner transforma hallazgos en acciones propuestas, pero no genera patches aplicables cuando falta contexto semántico o visual.

### Modelo

Acciones iniciales:

- `DESIGN_RLS_POLICY`
- `REVIEW_CROSS_FILTER_DIRECTION`
- `REPAIR_RELATIONSHIP_REFERENCE`
- `REVIEW_MODEL_FINDING`

Una relación `BothDirections` se revisa, pero V1.6 nunca la convierte automáticamente a `OneDirection`.

### Canvas

Acciones iniciales:

- `MOVE_WITHIN_CANVAS`
- `ALIGN_VISUALS`
- `REVIEW_Z_ORDER`
- `REVIEW_CANVAS_FINDING`

`EXPECTED_LAYERING` no genera acción. `POTENTIAL_OCCLUSION` y `CONTENT_OVERLAY` sí requieren revisión.

## S510 baseline usado para calibración

La ejecución real V1.5 informó:

- 20 tablas;
- 194 columnas;
- 416 medidas;
- 20 particiones;
- 2 relaciones;
- 0 roles / 0 table permissions;
- una relación `bothDirections`;
- `semantic_runtime_validated=false`.

Estos datos sirven para calibrar el motor, pero no se codifican como reglas específicas de S510.

## Próximo gate

Ejecutar `artel_plan_local_bi` contra el PBIP real en modo read-only con `expect_rls=true` cuando el objetivo sea aislamiento por vendedor. El resultado esperado es un plan, no una modificación.
